# Landing page (/)

Scope: the landing page and its header and footer. Mode: Persuade.

Audience: a Build Games judge or a solo founder with a few minutes. Job: understand what Firsthand is and get inside. Action: one, "Open the demo", which signs the visitor in anonymously and lands them in the shared demo dashboard. Secondary exits live only in the footer.

Principle from the user (4 Sept 2026): show, don't tell; as few words as possible. The inside of the product comes first; the landing page is finished last.

Current shape: header (mark, one button), a headline and one-line lede, the button, then the demo workspace's live wall widget pasted in with the same snippet a customer would use, a one-line caption, footer.

Constraints: no real customer testimonials exist for Firsthand itself; never invent counts, logos or press. No vendor names. Sibling discipline to SubbyFlow: one page, one action, no navigation, purple only where you act, rounded grammar, Inter Tight / Inter / Plex Mono on a warm off-white ground.

Unresolved: what else to show when the landing page is revisited. Candidates are the dashboard itself, the widget builder and the consent step, each shown live rather than described.
